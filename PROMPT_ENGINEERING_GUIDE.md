## 🏛️ Architectural Elements Dictionary

### Core Mediterranean Turkish Elements

#### 🏠 Bodrum Houses
- **Turkish:** Bodrum evleri
- **Characteristics:** White cubic structures, flat roofs, blue windows
- **Prompt Terms:** "Bodrum white cubic architecture", "whitewashed stone walls", "traditional Aegean houses"

#### 🔶 Muğla Red Clay Tiles
- **Turkish:** Muğla kiremitleri
- **Characteristics:** Terracotta red, curved traditional tiles
- **Prompt Terms:** "traditional Muğla red clay roof tiles", "Mediterranean terracotta roofing", "curved clay tile patterns"

#### 🏗️ Stone Chimneys
- **Turkish:** Taş bacalar
- **Characteristics:** Natural stone, conical or rectangular
- **Prompt Terms:** "traditional stone chimneys", "limestone chimney structures", "Mediterranean stone smokestacks"

#### 🌳 Olive Groves
- **Turkish:** Zeytin bahçeleri
- **Characteristics:** Silver-green leaves, gnarled trunks
- **Prompt Terms:** "ancient olive groves", "Mediterranean olive trees", "silver-leafed olive orchards"

#### 🌺 Bougainvillea
- **Turkish:** Begonvil
- **Characteristics:** Purple, magenta, or pink cascading flowers
- **Prompt Terms:** "purple bougainvillea cascading", "vibrant bougainvillea flowers", "Mediterranean flowering vines"

## 📝 Prompt Structure Templates

### 1. Basic Structure
```
[Subject] + [Location] + [Architecture] + [Nature] + [Lighting] + [Style] + [Technical] + [Negative]
```

### 2. Photorealistic Blog Image
```
[Engineering Equipment] on/in [Mediterranean Location],
[Architectural Elements],
[Natural Elements],
[Lighting Conditions],
professional architectural photography,
[Technical Specifications],
[Negative Prompts]
```

**Example:**
```
"Solar panels installed on traditional Bodrum villa rooftop,
white cubic architecture with blue window frames,
Muğla red clay tiles surrounding the installation,
purple bougainvillea cascading over stone walls,
ancient olive trees in foreground,
golden hour Mediterranean sunlight,
professional architectural photography, wide angle lens,
ultra high resolution 4K, sharp details,
no people, no text, no logos, no modern city elements"
```

```
Abstract [Service Type] visualization,
[Geometric Patterns] inspired by [Architectural Element],
[Color Gradients] from [Natural Element],
[Technical Style],
[Composition],
[Negative Prompts]
```

**Example:**

## 🚫 Negative Prompt Guidelines

### Always Exclude
```
no people, no faces, no human figures,
no text, no watermarks, no logos,
no modern city backgrounds,
no concrete blocks, no industrial zones,
no northern European architecture,
no pine trees, no lavender fields
```

### Style-Specific Exclusions

**For Photorealistic:**
```
no cartoon style, no illustrations,
no oversaturated colors, no HDR effects,
no artificial lighting, no neon colors
```

**For Abstract:**
```
no photorealism, no actual buildings,
no realistic shadows, no depth of field,
no camera effects, no lens flare
```

## 🎯 Prompt Optimization Tips

### 1. Specificity Hierarchy
```
Most Important → Least Important
1. Main subject (equipment/service)
2. Location/architecture
3. Natural elements
4. Lighting
5. Style modifiers
6. Technical specs
7. Negative prompts
```

### 2. Token Efficiency
- **Good:** "Bodrum white cubic villa"
- **Redundant:** "Traditional white-colored cubic-shaped Bodrum-style villa house"

### 3. Cultural Authenticity
- ✅ "Muğla red clay roof tiles"
- ❌ "Spanish terracotta tiles"
- ✅ "Aegean coastal architecture"
- ❌ "Mediterranean resort style"

### 4. Technical Accuracy
- ✅ "VRF multi-split system"
- ❌ "Air conditioning machine"
- ✅ "Photovoltaic panel array"
- ❌ "Solar electricity panels"

## 🔄 Iteration Strategies

### If Too Generic
**Add:** More specific architectural details
```
Before: "Mediterranean house"
After: "Bodrum cubic villa with blue wooden shutters and stone walls"
```

### If Wrong Region
**Replace:** Generic terms with specific locations
```
Before: "Mediterranean architecture"
After: "Muğla traditional architecture with red clay tiles"
```

### If Too Modern
**Emphasize:** Traditional elements
```
Before: "House with solar panels"
After: "Traditional stone house with solar panels integrated into clay tile roof"
```

### If Missing Nature
**Include:** Local flora
```
Before: "Villa terrace"
After: "Villa terrace with olive trees and purple bougainvillea"
```

## 🎯 Success Metrics

### High-Quality Prompt Indicators
- ✅ Generates consistent regional architecture
- ✅ Includes multiple Mediterranean elements
- ✅ Appropriate lighting for time of day
- ✅ Clear style distinction (photo vs abstract)
- ✅ No unwanted modern elements

### Common Failures to Avoid
- ❌ Generic "Mediterranean" without specifics
- ❌ Mixing architectural styles
- ❌ Wrong vegetation (pine instead of olive)
- ❌ Industrial or urban backgrounds
- ❌ Over-stylized or unrealistic colors
